# Xeneon

Widgets iCUE pour l’écran tactile **CORSAIR XENEON EDGE** (2560 × 720, 14,5"), tous dans le même style dot-matrix.

- [Charte graphique](DESIGN.md) : référence visuelle commune à tous les widgets.
- [Fiche type d’un widget](SPEC-TEMPLATE.md) : modèle de fiche à remplir pour chaque widget.

La liste des widgets est dans le [README du dépôt](https://github.com/Mathod95/xeneon#widgets).
