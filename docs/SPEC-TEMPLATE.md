# Nom du widget

**Statut :** ⚪ idée
**Dossier :** `widgets/<slug>`

## But
Ce que le widget affiche ou permet de faire, en une ou deux phrases.

## Tailles
Cocher les tailles à prendre en charge et décrire ce qui change entre elles.

- [ ] S (840 × 344)
- [ ] M (840 × 696)
- [ ] L (1688 × 696)
- [ ] XL (2536 × 696)
- [ ] Vertical

## Contenu et interactions
Ce qu’on voit, ce qu’on peut toucher, ce qui se passe au toucher.

## Données
D’où viennent les données : plugin iCUE (capteurs, FPS, média…), API externe, programme compagnon, réglages saisis dans iCUE.

## Réglages iCUE
Les options que l’utilisateur peut changer dans le panneau de réglages.

## Maquette
Lien ou image (dans `docs/widgets/img/`).
