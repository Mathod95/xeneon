Anatomie d'une subPage

La subPage est la page générique sous l'accueil: présentation, guide, FAQ, tout ce qui n'est ni l'accueil, ni une maquette, ni les versions (aujourd'hui Dot Companion). Le haut est toujours le même (en-tête, titre, accroche, faits, actions), puis viennent des sections, chacune avec son sur-titre, dans la forme qui convient à son contenu. Survole une étiquette pour repérer sa zone, ou passe en vue squelette pour voir ce qui remplit chaque bloc.
