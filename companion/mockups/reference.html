Dot Companion

Le programme qui tourne sur le PC et fait marcher Dot Hub : il sert les modules à l'Edge et garde leurs réglages. La vue « Réglages » charge la vraie page du compagnon (companion/web/settings.html) et les vrais réglages des modules (balises x-icue-property de chaque index.html), avec des Dot Hub d'exemple à la place du compagnon.

Proposition · réglages avec l'Edge en direct

Idée de Mathias, 28 octobre 2026. À faire d'abord dans cette maquette, puis dans le compagnon une fois validée.

À la place de la page de réglages actuelle : l'écran de la CORSAIR XENEON EDGE en haut, avec chaque Dot Hub qui tourne en direct, et en dessous ses réglages présentés comme dans les maquettes de référence. Chaque changement se voit tout de suite sur l'écran.

Pourquoi c'est faisable

  • Le rendu des modules existe déjà : le compagnon sert les vraies pages des modules (Dot Clock, Dot Steam), et c'est le même rendu dans les maquettes et sur l'Edge. Il suffit de les afficher dans un cadre d'Edge, comme sur Dot Page.
  • Le direct existe presque : un module relit ses réglages toutes les 2 s ; la page de réglages peut en plus envoyer chaque changement à l'aperçu (postMessage) pour qu'il soit instantané.
  • Les vraies données : sur le PC, l'aperçu montre les vrais jeux Steam, la vraie heure, etc., puisque c'est le compagnon qui les fournit.

À quoi ça ressemblerait

  • En haut : l'écran de l'Edge, et la liste des Dot Hub (leur nom) à côté pour choisir celui qu'on règle.
  • En dessous : les réglages au style des maquettes (boutons de choix, interrupteurs, pastilles de couleur) au lieu de listes déroulantes. Toujours générés depuis les balises x-icue-property de chaque module : rien à refaire module par module.
  • Mode aperçu : toucher l'aperçu ne déclenche rien (pas de jeu lancé, pas de lumière allumée).

Limites

  • La place sur l'Edge : iCUE ne dit pas au compagnon où chaque widget est posé ni sur quelle page. Sa taille (S, M, L, XL) peut être envoyée par le module au compagnon (petit ajout), pas sa position. Chaque Dot Hub s'affiche donc à sa vraie taille, sans reproduire exactement la disposition ; option : le placer soi-même dans l'aperçu, pour l'affichage seulement.
  • Les modules pas encore codés : seuls Dot Clock et Dot Steam tournent en direct aujourd'hui ; les autres arriveront au fur et à mesure qu'ils seront codés.
  1. Maquette : l'Edge en direct avec les Dot Hub d'exemple et les vrais Dot Clock et Dot Steam, réglages au style des maquettes.
  2. Compagnon : la même page dans companion/web/settings.html, taille envoyée par chaque Dot Hub, mode aperçu dans les modules.

Choix de design

Les lignes sans gris sont déjà dans le compagnon 0.4.0 ; les grises sont à valider.

#ÉlémentProposition
1RôleSeul programme à installer sur le PC. Sert l'accueil de Dot Hub et chaque module (/m/<id>/), garde les réglages de chaque Dot Hub posé dans iCUE (%APPDATA%\Xeneon\config.json) et fait ce qu'un widget ne peut pas faire seul : lire les fichiers de Steam, lancer des jeux, parler aux services.
2RéseauN'écoute que sur 127.0.0.1:47800 : invisible depuis le réseau local. Les requêtes dont l'en-tête Host n'est pas 127.0.0.1:47800 ou localhost:47800 sont refusées.
3RéglagesDans le navigateur du PC (bouton ⚙ SETTINGS de l'accueil). Une carte par Dot Hub : nom, module, champs du module générés depuis ses balises x-icue-property, enregistrés tout de suite. Carte « Couleurs » commune à tous les modules. « Identifier » affiche le nom sur l'Edge, « Oublier » demande confirmation.
4SecretsClés d'API et jetons chiffrés sur le PC (DPAPI de Windows), masqués dans la page (••••••••), jamais renvoyés en clair.
5FenêtreAujourd'hui une fenêtre console : la fermer arrête le compagnon. Proposition : plus de fenêtre, une icône dans la zone de notification (vue « Zone de notification »).
6Menu de l'icôneOuvrir les réglages, Identifier les Dot Hub, Démarrer avec Windows (coché par défaut), Rechercher une mise à jour, Quitter. En tête : version et nombre de Dot Hub connectés. Clic gauche sur l'icône : ouvre les réglages.
7Démarrage avec WindowsClé HKCU\Software\Microsoft\Windows\CurrentVersion\Run, sans droits administrateur. Activé à la première ouverture, désactivable dans le menu.
8Mises à jourCompare sa version à la dernière release GitHub (au démarrage, puis une fois par jour) ; une nouvelle version s'affiche dans le menu et dans la page de réglages, avec un lien de téléchargement. Pas de mise à jour automatique pour l'instant.
9Avertissement WindowsL'exe n'est pas signé : SmartScreen avertit au premier lancement (« Informations complémentaires » → « Exécuter quand même »). Pistes : Microsoft Store (MSIX, aucun avertissement) ou signature gratuite SignPath pour les projets open source.
10Charte de la page de réglagesFond en points de Dot Page : fait (page #080808, trame de points 22 px). Reste : le libellé « ● DOT COMPANION » ; garder la police Fira Code et l'accent des Couleurs communes.
