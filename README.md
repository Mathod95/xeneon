# Xeneon

Widgets iCUE pour l’écran tactile CORSAIR XENEON EDGE.

Tous les widgets partagent le même style dot-matrix.

La colonne **Compagnon** indique si le widget a besoin du programme compagnon Windows (à construire) : **Oui** s’il ne marche pas sans, **Optionnel** s’il s’en sert pour un repli ou une sauvegarde, **Non** s’il est autonome.

## Widgets
