# Dot Calendar

**Statut :** 🔵 spécifié

Horloge, calendrier du mois, semaine, agenda et compte à rebours avant le prochain événement.

## Contenu et interactions

- Horloge dot-matrix, AM/PM, jour et date.
- Prochain événement : « NEXT · IN 18 MIN », titre, horaire, lieu ou visio, bouton JOIN (Meet, Zoom, Teams).
- Mois : jours avec points d’événements, aujourd’hui entouré, navigation mois précédent / suivant au swipe ou aux flèches, tap sur un jour.
- Semaine : colonnes jour par jour avec événements.
- Agenda : aujourd’hui, demain, jours suivants.
- Thèmes clair et sombre, couleur d’accent au choix.

## Données

- Calendriers Google, Outlook, iCloud via liens ICS privés (réglages iCUE).
- Si un serveur refuse la lecture directe depuis le widget : le compagnon récupère l’ICS.
- Jours fériés de 200+ pays intégrés, hors ligne.
- JOIN : plugin iCUE Liens.
