# Dot Sonarr

**Statut :** ⚪ idée

Séries Sonarr : épisodes en téléchargement, prochains épisodes à sortir et épisodes manquants, recherche relancée d’un toucher. Module de Dot Hub, servi par Dot Companion.

## Données

- API de Sonarr (`/api/v3/…`) avec la clé d’API (en-tête `X-Api-Key`), gardée chiffrée sur le PC : file de téléchargement (`/queue`), calendrier (`/calendar`), séries (`/series`).
- Affiches des séries en trame de points, chargées depuis ton serveur Sonarr.
