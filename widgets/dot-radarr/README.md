# Dot Radarr

**Statut :** ⚪ idée

Films Radarr : téléchargements en cours avec progression, prochaines sorties et films manquants, recherche relancée d’un toucher. Module de Dot Hub, servi par Dot Companion.

## Données

- API de Radarr (`/api/v3/…`) avec la clé d’API (en-tête `X-Api-Key`), gardée chiffrée sur le PC : file de téléchargement (`/queue`), calendrier (`/calendar`), films (`/movie`).
- Affiches des films en trame de points, chargées depuis ton serveur Radarr.
