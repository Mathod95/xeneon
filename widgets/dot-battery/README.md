# Dot Battery

**Statut :** ⚪ idée

Niveau de batterie des périphériques sans fil, état de charge et alerte de batterie faible.

## Données

- Appareils CORSAIR : plugin iCUE Sensors.
- Casque Logitech : compagnon, via le protocole sans fil Logitech (HID++), sans G HUB.
- Appareils Bluetooth : compagnon, niveau connu de Windows.
