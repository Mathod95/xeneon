# Dot Seerr

**Statut :** ⚪ idée

Demandes de films et de séries de Seerr : en attente, approuvées et disponibles, avec approuver ou refuser d’un toucher. Module de Dot Hub, servi par Dot Companion.

## Données

- API de Seerr (`/api/v1/request`) avec la clé d’API (en-tête `X-Api-Key`), gardée chiffrée sur le PC.
- Actions : approuver ou refuser une demande (`/api/v1/request/<id>/approve`, `/decline`).
