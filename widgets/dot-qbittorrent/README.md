# Dot qBittorrent

**Statut :** ⚪ idée

Téléchargements qBittorrent : débit montant et descendant en direct, torrents en cours avec progression, pause, reprise et limite de vitesse alternative. Module de Dot Hub, servi par Dot Companion.

## Données

- API de l’interface web de qBittorrent (`/api/v2/…`) : connexion (`/auth/login`), torrents (`/torrents/info`), débit (`/transfer/info`), limite alternative (`/transfer/toggleSpeedLimitsMode`).
- Identifiants de l’interface web gardés chiffrés sur le PC.
